========================================================

Implement actual failure replay.

The replay mechanism must reconstruct the context available to the
agent at a recorded decision point.

A replay should include, as available:

input

Expose programmatic API:

step-by-step.

10. CI/CD RELIABILITY GATE
========================================================

Implement:

agentguard ci-gate --threshold=5

Purpose:

Prevent deployment when candidate reliability regresses beyond the
configured threshold.

Flow:

CI
 ↓
Historical regression corpus
 ↓
Replay/evaluate candidate
 ↓
Compare baseline vs candidate
 ↓
Calculate regression
 ↓
PASS / BLOCK

The command must return:

exit code 0 = allowed

non-zero = blocked

The threshold must be configurable.

Do NOT block deployment because of a metric that is unavailable.

Document exactly which metrics participate in the gate.

Do not silently invent a weighting formula.

========================================================
11. CI GATE RULE

BLOCK
