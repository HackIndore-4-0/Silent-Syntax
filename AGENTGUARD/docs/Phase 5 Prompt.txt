AGENTGUARD — DASHBOARD V2 + MULTI-USER AUTHENTICATION

The current AgentGuard dashboard is functionally rich but has poor UX.
The current UI looks like an internal engineering/debug page rather than a
professional observability platform.

Do NOT add another feature phase.
This task is a UX/platform redesign of the existing Phase 1–4 implementation.

OBJECTIVE

Redesign AgentGuard into a polished enterprise-grade observability and
reliability dashboard inspired by the information architecture of products
such as LangSmith, Datadog and Grafana, WITHOUT copying their UI.

The platform must support multiple users with strict tenant/user data isolation.

Preserve all existing AgentGuard backend functionality and tests.

==================================================
15. SDK INTEGRATION
==================================================

Modify the AgentGuard Python SDK so users can connect their local agent
to their AgentGuard account.

Preferred usage:

from agentguard import AgentGuard

guard = AgentGuard(
    api_key=os.getenv("AGENTGUARD_API_KEY"),
    project="production"
)

@guard.monitor
def my_agent():
    ...

Also support:

guard = AgentGuard()

where AGENTGUARD_API_KEY is automatically loaded from the environment.

The SDK must send:
- authenticated user/project identity
- agent name
- run data
- spans
- evaluation results
- tool calls
- token metadata when available
- latency metadata
- recovery/intervention events

Do NOT expose AgentGuard private credentials in frontend JavaScript.
API keys belong to server-side agent code/environment.
